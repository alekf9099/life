# ONCE · 한 번의 생

> 내가 받은 운은 손주에게까지 닿을까?
> 44개국 실제 통계로 3대를 살아 보는 대물림 시뮬레이션.

![ONCE](icons/og.png)

## 특징

| | |
|---|---|
| 🌳 **3대 가계도** | 나 → 내 아이 → 내 손주. 형편·배움·이주·유산·이른 이별이 다음 세대의 출발선이 됩니다 (지역별 세대 간 상관 ρ 적용) |
| 📅 **오늘의 아이** | 날짜 시드로 모두가 같은 아이로 태어나요. 연속 기록 🔥과 워들식 이모지 결과 공유 |
| 🧭 **다양한 환경** | 태풍·지진·폭염·가뭄·홍수·혹한·미세먼지, 도시/시골, 이민 2세, 팬데믹·경제위기·AI, 나라별 명절 |
| ⚖️ **고르게 나오는 질문** | 7개 분야(배움·일·사랑·건강·이주·관계·가치) 약 30개 질문 중 덜 나온 분야부터. 형식은 선택·모험·배분·딜레마 |
| 🌍 **실제 확률로 태어나기** | 출생아 수 비례(또는 모든 나라 균등)로 나라를 뽑고, 집안 형편·성별·도시/시골이 정해집니다 |
| ⏱️ **3 / 8 / 15분 한 생** | 출퇴근길에 끝나는 짧은 인생. 1×–16× 배속, 일시정지 |
| 👶 **동갑내기 100명** | 그 나라 생명표 기준으로 같은 해 태어난 100명이 하나씩 사라집니다 |
| 🧾 **인생 영수증** | 삶이 끝나면 영수증으로 요약 → 이미지로 저장·공유 (Android 공유 시트 지원) |
| ✨ **나의 별자리** | 끝까지 살아 낸 삶은 별이 됩니다 (기기에만 저장) |
| 📱 **PWA** | 홈 화면에 설치, 오프라인 실행, 화면 꺼짐 방지, 진동 피드백 |

## 계산 방법

- **수명**: 영아사망률 + 곰페르츠 사망 곡선을 국가 기대수명에 맞춰 보정 (시뮬레이션 평균이 실제 기대수명과 대체로 1–3년 이내)
- **소득**: 1인당 GDP(PPP)와 지니계수로 로그정규 분포 → 가족 형편·교육연수로 위치 결정
- **교육·결혼·출산**: 평균 교육연수, 대학 취학률, 합계출산율을 형편에 따라 조정

데이터 출처: UN WPP, World Bank WDI, UNICEF/WHO, UNDP HDR, World Happiness Report (2022–2023 근사치, 반올림)

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 배포합니다.
(저장소 Settings → Pages → Source를 **GitHub Actions**로 설정)

## 구조

```
index.html            화면 6개 (홈 · 출생 · 삶 · 끝 · 별자리 · 정보)
css/style.css         밤하늘 테마 (다크/라이트)
js/data.js            국가 통계
js/sim.js             시뮬레이션 엔진
js/app.js             UI · 저장 · 공유
sw.js                 오프라인 캐시
manifest.webmanifest  PWA 설정
```
