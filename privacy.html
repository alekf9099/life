★ ONCE

개인정보처리방침

시행일: 2026년 10월 12일

1. 수집하는 정보

ONCE(이하 “앱”)는 이름, 연락처, 위치, 기기 식별자 등 어떠한 개인정보도 수집하지 않습니다. 회원가입과 로그인이 없으며, 서버로 전송되는 사용자 데이터가 없습니다.

2. 기기에 저장되는 정보

지난 삶의 기록, 별자리, 오늘의 아이 연속 기록, 화면 설정, 사용자가 선택한 ‘실제 태어난 나라’는 사용자의 기기 브라우저 저장소(localStorage)에만 저장됩니다. 이 정보는 운영자를 포함한 누구에게도 전송되지 않으며, 앱의 ‘모든 별 지우기’ 또는 앱 데이터 삭제로 언제든 지울 수 있습니다.

3. 외부 서비스

앱은 글꼴(Pretendard)을 jsDelivr CDN에서 불러오고, 웹 페이지는 GitHub Pages에서 제공됩니다. 이 과정에서 각 서비스가 일반적인 접속 기록(IP 주소 등)을 처리할 수 있으며, 이는 각 서비스의 개인정보처리방침을 따릅니다. 앱은 광고, 분석 도구, 추적 기술을 사용하지 않습니다.

4. 공유 기능

‘이미지로 공유’, ‘결과 복사·공유’는 사용자가 직접 누를 때에만 기기의 공유 기능을 통해 동작하며, 무엇을 누구와 공유할지는 사용자가 결정합니다.

5. 아동의 개인정보

앱은 개인정보를 수집하지 않습니다. 다만 질병, 빈곤, 분쟁, 죽음 등 무거운 내용이 통계에 따라 등장하므로 15세 이상 이용을 권장합니다.

6. 변경 및 문의

방침이 바뀌면 이 페이지에 게시합니다. 문의는 GitHub 저장소(github.com/alekf9099/life)의 Issues로 남겨 주세요.
